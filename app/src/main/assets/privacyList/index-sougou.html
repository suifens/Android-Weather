主要向您说明优量汇SDK收集哪些信息、收集信息的用途及您所享有的权利，希望您仔细阅读本声明，详细了解我们对信息的收集、使用方式，以便您更好地了解我们的服务并作出适当的选择。收集如下信息，用于以下使用目的。
（2.1） 获取粗略位置用于第三方广告，我们将收集粗略位置信息，用于广告投放与监测归因。
（2.2）获取标识符 Identifiers，用户ID User ID，设备ID Device ID用于第三方广告， 当用户授权应用使用标识符时，我们将收集广告标识符用于广告投放与监测归因。
（2.3）获取使用数据 Usage Data，产品交互 Product Interaction，广告数据 Advertising Data用于第三方广告，我们将统计展示 、点击 、转化广告数据，以用于广告主统计投放结果。
（2.4） 获取诊断 Diagnostics，崩溃数据 Crash Data，性能数据 Performance Data用于app功能，我们将收集运行过程中的崩溃信息、性能数据，大程度减少App崩溃、确保服务器正常运行、提升可扩展性和性能。
（2.5）获取其他数据 Other Data，其他数据类型 Other Data Types用于第三方广告，技术上我们将收集一些设备信息（例如，系统语言、屏幕高宽、屏幕方向、屏幕DPI信息等）。
如我们收集的信息无法单独或结合其他信息识别到您的个人身份，其不属于法律意义上的个人信息；当您的相关信息可以单独或结合其他信息识别到您的个人身份，或者我们将无法与任何指定个人建立联系的数据与其他您的个人信息结合使用时，这些信息在结合使用期间，将作为您的个人信息并按照本声明处理与保护。请您仔细阅读《优量汇SDK隐私保护声明》。

基于为您提供个性化内容展示和定制化广告推荐的业务功能目的，我们将通过大数据分析、算法等非人工自动决策技术，对于我们直接收集的上述信息（设备信息和日志信息）进行标签化处理并形成画像，用以做出自动化决策决定（如商业化信息展示）。同时，我们将可能与数据分析服务商、效果广告服务商合作，间接获取您的其他群体标签信息，其中可能涉及您的个人信息（包括您的手机品牌、所在城市、兴趣爱好），以为您提供更为精准的个性化内容展示和广告推荐服务。
